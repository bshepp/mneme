# Steady State

Steady-state and distinct-state analysis of relaxing systems: has a run settled, and how many distinct end states do several runs reach? All functions take a trajectory of shape `(n_times, n_cells)` with no spatial interpolation. Core tier; see [Scope and Support Status](../../SCOPE.md) and the [Multistability Protocol](../../MULTISTABILITY_PROTOCOL.md).
