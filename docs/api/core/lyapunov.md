# Lyapunov

Largest Lyapunov exponent (Rosenstein 1993) and an exploratory full spectrum.

Frozen tier: kept as is, not under development. Read the [Lyapunov Operating Range](../../LYAPUNOV_OPERATING_RANGE.md) before using a number from these. Continuous flows only; not for discrete maps or transients. `lyapunov_spectrum` requires more than 100 points and warns below 1000.
